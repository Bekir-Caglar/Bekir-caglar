## Hakkımda

Karadeniz Teknik Üniversitesi Bilgisayar Bilimleri 4. sınıf öğrencisiyim. **Android, Kotlin ve Jetpack Compose** ile mobil uygulamalar geliştiriyorum. Kotlin Multiplatform ile Android ve iOS arasında ortak iş mantığı ve veri katmanları kuruyor, mobil uygulamaları backend servisleriyle bir araya getiriyorum.

Uygulama geliştirmeden mağaza yayınına uzanan süreçlerde çalışıyorum. Geliştirdiğim **Yazar-Eser Testleri**, 15.000+ indirmeye ulaştı.
